What You'll Learn Over the Weekend

The workshop tutorial takes you on a structured journey across two intensive, fun-filled days. By the time you finish, you will have built and deployed a working project:

1

The Environment Setup

Setting up Python, Visual Studio Code, understanding the terminal, and learning how a computer runs your instructions.

2

Python Foundations

Variables, numbers, strings, lists, loops, and conditional logic. The fundamental building blocks of all software.

3

Functions & Reusability

Writing your own custom functions, understanding inputs and outputs, and organizing code neatly so it is readable and reusable.

4

Beginner AI Project

Connecting Python to an intelligent model to build an interactive command-line assistant that responds to user questions.
