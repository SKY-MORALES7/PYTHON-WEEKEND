About

What is Python Weekend?

Python Weekend is a community-run, hands-on workshop for people who want to learn Python and Django by actually building something. No slides-only lectures — you write real code, ship a real app, and leave with something to show.

Our approach

We keep groups small, pair beginners with experienced coaches, and structure the day around a single project that grows as attendees learn. By the end, everyone has a working Django app they built themselves.

The format is inspired by Django Girls — this project is not affiliated with Django Girls, but we gratefully reference their workshop structure and open-source ethos.

Design & tech

This site is built with Django 5, Tailwind CSS, and a fair bit of enthusiasm. The color palette — red, navy, ice — is the Python Weekend shield palette. If you want to explore the code, it's open-source under the MIT license.
