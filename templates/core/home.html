What is Python Weekend?

♥

Python Weekend is a community initiative that empowers and helps people organise free, intensive programming workshops by providing tools, resources, and support.

We are a volunteer-run organisation. During each event, 20–60 attendees build their first web application using HTML, CSS, Python and Django.
